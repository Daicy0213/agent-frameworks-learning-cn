# 第 12 章学生练习：审批到底批准了什么

从 `solution.py` 开始，只实现 `approve_request`，不要先打开参考答案。

输入契约：principal 来自服务端认证；request 是不可信模型参数；approval 是服务端查询出的记录（不存在时为 `{}`）；now 是整数时间戳。只有 agent 角色、相同租户与用户、相同订单与整数金额、尚未过期且未被使用的审批才返回 True；其他情况返回 False。金额单位为分，范围 1～10000，bool 不是合法金额。

先预测：有效期等于 now 时是否有效？同一个审批能否给另一个用户使用？

在仓库根目录运行：

```bash
uv run python google-adk/practice/student_security/verify.py
```

初始状态会报 `NotImplementedError`，这是刻意保留的学习任务。补完后必须通过独立验收的 10 个断言。提示顺序：先查角色 → 再查金额类型 → 再逐字段比较 → 最后查有效期和已消费标记。完成后可用 `--reference` 运行参考实现。

这只是业务校验的纯函数部分。对真实退款，还必须在一个事务中复核审批、写账本并消费审批；参见第 12、15 章。

# Capstone：可上线的售后 Agent

本目录不是第二个 Agent 工程，而是一套**验收器**：把前 12 章的关键能力串成一条可执行流水线，验证它们在同一套约束下仍然成立。

## 阶段与对应章节

| 阶段 | 验证什么 | 章节 | 验收方式 |
|---|---|---|---|
| 1. 工具与护栏 | 工具状态、输入拦截、高风险策略与幂等 | 04、07、12 | 离线脚本断言 |
| 2. 会话与记忆 | 状态作用域、跨会话偏好、持久化边界 | 06 | 离线脚本断言 |
| 3. 评估 | 评估集规模、分类覆盖、断言字段 | 10 | 离线 schema 校验 |
| 4. 服务化 | `adk api_server` 可启动，`/run` 可返回事件 | 02、11 | HTTP 调用 |
| 5. 安全 | 护栏、脱敏、最小权限 | 12 | 离线脚本断言 |

## 运行

只跑离线阶段（不调用模型）：

```bash
cd google-adk
uv run --project .. python -m capstone.verify
```

额外验证本地 HTTP 服务（会调用一次 DeepSeek）：

```bash
uv run --project .. --env-file ../.env python -m capstone.verify --with-server
```

退出码：全通过为 `0`，任一阶段失败为 `1`。这条规则可以直接接进 CI。

## 评分标准（自评/评审）

| 维度 | 不合格 | 合格 | 优秀 |
|---|---|---|---|
| 工具 | 只有 happy path | 覆盖失败与非法输入 | 工具本体复核权限 |
| 会话 | 只用内存 | 能跨进程恢复 | 说明存储边界与过期策略 |
| 评估 | 手工试一下 | 有评估集与阈值 | 门禁能失败并进 CI |
| 服务 | 本机跑通 | 可重复启动与调用 | 有健康检查、限流、回滚 |
| 安全 | 只有提示词约束 | 有护栏与脱敏 | 最小权限 + 审批 + 审计 |

## 边界

- 验收器验证的是"机制是否按预期工作"，不验证"回答质量"；后者由第 10 章的在线评估负责。
- 多进程并发发布、分布式事务不在本 Capstone 范围内，第 09 章已经说明边界。
